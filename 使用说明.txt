订单发票比对工具 — 使用说明
================================

一、运行
1. 将整个「订单发票比对工具」文件夹拷贝到目标电脑（Win10 x64）。
2. 双击「订单发票比对工具.exe」（勿只拷单个 exe，需保留 _internal）。
3. 程序为本地离线工具，不联网上传数据；目标机需有 WebView2（Win10/11 一般已带）。

二、若 360 / 杀软提示「木马 / 病毒」（误报说明）
本程序用 Python + PyInstaller 打包，未购买代码签名证书时，360、Windows Defender
等常会把「未签名的自解压式 exe」误判为木马。这是行业常见误报，并非程序含病毒。

处理办法（以 360 安全卫士为例，其他杀软类似）：
1. 打开 360 →「病毒查杀」或弹窗详情 → 选择「信任 / 添加信任 / 恢复」。
2. 或打开「信任区 / 白名单」，把整个文件夹加入信任：
   …\订单发票比对工具\
3. 若文件已被隔离：到「隔离区 / 恢复区」恢复后再加入信任。
4. 公司电脑若被策略锁定，请联系 IT 将本目录加入杀软与 Soft Restriction 白名单。

可选：向 360 提交误报（官网「软件报毒申诉」），附上本工具说明与来源。
根治方案：购买并使用 Windows 代码签名证书对 exe 签名（需公司主体与费用）。

三、界面操作
1. 可先点「格式说明」查看必填列；或点「下载订单模板 / 下载发票模板」获取带样例的 Excel。
2. 选择「订单数据」Excel（需含：交货日期、型号、数量、用户价格）。
3. 选择「发票数据」Excel（需含：开票日期、规格型号、数量、单价）。
4. 选择发票文件后，将自动推断「周期起始日/结束日」（开票日所在月月初～月末），
   可再手动修改；「账期」单位为天，默认 30 天。
5. 指定结果保存路径，点击「导出比对结果」（进度条显示百分比）。
6. 导出成功后可点「打开比对结果」。

四、结果说明
- 打开结果中的「匹配明细」，可用「核实优先级」筛选高/中，找数据方沟通。
- 对发票方沟通时可隐藏订单专区列；对订单方沟通时可隐藏发票专区列。
- 详细规则见结果簿「规则说明」工作表，或项目 README.md。

五、其他
- 目标机无需安装 Python；用 WPS/Office 打开结果即可。
- 程序为 64 位。
- 业务 Excel 数据仅在本地读写，不会上传网络。
